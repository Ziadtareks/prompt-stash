## Example AI response

**1. THE FORMULA**
On the Summary sheet, put the chosen month in `B1` (format it as a date, e.g. Jan-2026) and the salesperson name in `B2`:

```excel
=SUMIFS(Sales!C:C, Sales!B:B, "*"&TRIM(B2)&"*", Sales!A:A, ">="&B1, Sales!A:A, "<"&EDATE(B1,1))
```

For the dropdown: select `B2` → Data → Data Validation → List → source `=Sales!$B$2:$B$500` (or a separate hidden list of unique names).

**2. HOW IT WORKS**
- `SUMIFS` — adds the values in `Sales!C:C` but only for rows matching every condition.
- `Sales!B:B, "*"&TRIM(B2)&"*"` — matches the salesperson name ignoring the extra spaces in your data (`TRIM` cleans the picker value; the wildcards absorb stray spaces in the Sales sheet).
- `Sales!A:A, ">="&B1` — only rows on or after the first day of the chosen month.
- `Sales!A:A, "<"&EDATE(B1,1)` — only rows before the first day of the *next* month (`EDATE` adds one month), so month lengths don't matter.

**3. EDGE CASES HANDLED**
- Blank amounts: `SUMIFS` treats them as 0 — no error, they're just skipped.
- Names with extra spaces: handled both sides (TRIM + wildcards).
- Wrong month picked (no matching rows): returns a clean `0`, not an error. If you'd rather see "No data": `=IF(SUMIFS(...) = 0, "No data", SUMIFS(...))` — repeat the SUMIFS inside.

**4. ALTERNATIVE**
A **PivotTable** (Insert → PivotTable → rows: salesperson, columns: date grouped by month, values: sum of amount) plus a slicer does this with zero formulas and refreshes in one click. Prefer the formula when you need the number inside other calculations; prefer the pivot when the Summary sheet is for reading only.
