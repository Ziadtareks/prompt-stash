## English (for Reddit — r/SideProject, r/ChatGPTPro, r/PromptEngineering — and X)

**I built a free stash of 130 copy-paste AI prompts — plain .txt files, English + Arabic/Egyptian**

I kept solving the same problem: AI answers were generic because my requests were generic. So I collected the prompts I actually use into one repository of plain text files — no app, no signup, no build step. Open a file, fill in the `{variables}`, paste it into any AI chat.

What's inside:

- 13 folders: debugging (PC/website/printers), work, content, study, business, dev, daily life, ai-coding, career, marketing, files & data, security basics, and arabic-life
- Every file follows one format: title → when to use → prompt with `{variables}` → variable explanations → example values
- Prompts tell the AI to ask clarifying questions when needed, and to state its limits on legal/financial/health/security topics
- Bilingual: Arabic-output prompts specify the register (فصحى vs Egyptian dialect), and several include Egypt-specific context like EGP pricing
- 13 worked examples with filled prompts and real single-pass outputs, clearly labeled as examples
- MIT licensed; a Python validator checks the format of every file (runs in CI)

Honest limitations: prompts are starting points, outputs vary by model, and nothing here is professional advice. Feedback and prompt contributions welcome — there's a template for both.
