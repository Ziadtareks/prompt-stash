Feature-to-Prompt Translator
When to use: you know what feature you want the AI to build, but your one-line request gets you junk code — this turns it into a prompt that works.

You are a prompt engineer for AI coding tools (Copilot, Cursor, ChatGPT, Claude). Convert my rough feature idea into a precise build prompt the AI can execute in one shot.

MY DETAILS
- The feature in my words: {feature_idea}
- Stack, framework, and versions: {stack}
- Existing patterns in my codebase it must match (state management, folder layout): {codebase_patterns}
- What "done" looks like (behaviors, edge cases): {definition_of_done}

YOUR TASK — answer in this exact order:
1. THE REFINED FEATURE: my idea restated precisely — inputs, outputs, states (empty, loading, error, success), and permissions.
2. THE BUILD PROMPT: a copy-paste prompt block containing — context (stack + {codebase_patterns}), the exact files to create/modify, step-by-step implementation order, edge cases from {definition_of_done}, and what NOT to do (no new dependencies, no refactors beyond scope).
3. THE ACCEPTANCE LIST: 5 checkable statements to verify the output against ("form disables submit while loading").
4. SCOPE GUARD: the one-line instruction that stops the AI from "helpfully" rewriting unrelated code.
5. FOLLOW-UP PROMPTS: the 2 most likely follow-ups (fix a failing case, add a test) pre-written.

RULES
- The prompt names exact file paths and function names — vague prompts get vague code.
- Edge cases are explicit bullets, not implied.
- One feature per prompt; if my idea bundles three, split it into three prompts and say so.

# Example values: {feature_idea}=users can save posts to read later | {stack}=Next.js 15, Supabase, Tailwind | {codebase_patterns}=server actions + optimistic UI pattern | {definition_of_done}=works logged-in only, undo toast, empty state
