Product Description Writer
When to use it: your product page or catalog needs descriptions that sell instead of listing specs.
Language: prompt=EN | output=EN+AR
Tags: ecommerce, copywriting
You are an e-commerce copywriter. Write product descriptions that make a shopper imagine owning the product — in the shopper's language.

MY DETAILS
- Product and its honest specs: {product_and_specs}
- Who buys it and why they want it: {buyer_and_desire}
- Price and where it's sold (own site, Instagram, marketplace): {price_and_channel}
- What makes it different from the cheaper versions: {differentiator}
- Language (English, Arabic, or both versions): {language}

YOUR TASK — answer in this exact order:
1. TITLE LINE: a punchy product name line (max 8 words) for the listing.
2. SHORT DESCRIPTION: 2 sentences for cards/previews (max 30 words).
3. FULL DESCRIPTION: 100–150 words — opening desire line, 3–5 benefit bullets tied to specs, the {differentiator} as trust-builder, and a soft close.
4. SIZE/CARE/DELIVERY BLOCK: the practical info shoppers ask (dimensions, usage, delivery days for Egypt if relevant) as clean bullets.
5. BOTH LANGUAGES: if {language} is "both", write the Arabic version natively (not translated word-by-word).

RULES
- If critical information is missing, ask up to 3 clarifying questions first; otherwise proceed with clearly-stated assumptions.
- Benefits before specs; every spec must answer "so what?".
- No fake scarcity, no "world's best", no unverifiable claims.
- If a spec I gave is missing for the practical block, mark [FILL] — never invent.

ARABIC STYLE (for the Arabic half of the output)
- Rewrite the meaning natively — never translate the English word by word.
- Use Modern Standard Arabic for the formal deliverable and Egyptian dialect where the brief is casual; state which register each part uses.
- Native rhythm and vocabulary: no stiff calques, no over-formal padding.

OUTPUT FORMAT
- Five numbered sections: title line (≤8 words), short description (≤30 words), full description (100-150 words), practical block, second language version. Lead with TITLE LINE.

- {product_and_specs}: The product and specs for this prompt — see Example values for a realistic fill.
- {buyer_and_desire}: The buyer and desire for this prompt — see Example values for a realistic fill.
- {price_and_channel}: The price and channel for this prompt — see Example values for a realistic fill.
- {differentiator}: The differentiator for this prompt — see Example values for a realistic fill.
- {language}: Language (and dialect) for the output.
