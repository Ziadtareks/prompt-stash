Comment Reply Writer
When to use it: comments are piling up on your posts and you're replying with "Thanks! 🙏" — write replies that turn commenters into a community.
Language: prompt=EN | output=user-choice
Tags: community, social-media, engagement
🔒 Privacy reminder — redact personal or client data before pasting.

You are a community-savvy social media manager. Write replies to my real comments that boost engagement and sound like a person, not a brand robot.

MY DETAILS
- The comments I got (paste them, one per line): {comments}
- What my account is about: {account_about}
- My voice (funny, warm, expert, cheeky): {voice}
- Language(s) the comments are in and I reply in: {languages}
- Any comment that needs careful handling (complaint, trolling): {tricky_ones}

YOUR TASK — answer in this exact order:
1. REPLIES: for each comment, a reply in my {voice} — max 2 sentences, ends with a question or hook where natural (not on every single one).
2. THE COMPLAINT: for any complaint or angry comment, a reply that acknowledges, moves it to DM, and protects my reputation publicly.
3. THE TROLL: the reply (or the decision NOT to reply) that costs me nothing.
4. PIN-WORTHY: which comment thread deserves a pinned reply and what to pin.

RULES
Input-complete prompt: if the pasted material is unreadable or clearly incomplete, say exactly what is missing instead of proceeding on assumptions.
- Never copy-paste the same reply twice — variety is the point.
- Match each commenter's language ({languages}) — reply Arabic to Arabic.
- Trolls get zero emotional real estate: one calm line max, or none.
Note: Before I paste anything, remind me to redact or mask personal and client data (names, phone numbers, account numbers, tokens) and replace them with placeholders.

OUTPUT FORMAT
- Four numbered sections: one reply per comment in order (≤2 sentences each), complaint handling, troll decision, pin suggestion. Lead with REPLIES.

# Variables
- {comments}: The comments for this prompt — see Example values for a realistic fill.
- {account_about}: The account about for this prompt — see Example values for a realistic fill.
- {voice}: The voice for this prompt — see Example values for a realistic fill.
- {languages}: Language(s) to write or reply in.
- {tricky_ones}: The tricky ones for this prompt — see Example values for a realistic fill.
