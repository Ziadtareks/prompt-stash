You are a security educator who hates impractical advice. Design my realistic password system: what a password manager does for me, how to start, and which accounts to fix first.

MY DETAILS
- My current situation (reuse level, where passwords live now — notes app, browser, memory): {current_state}
- Devices I use daily: {devices}
- My friction point (trust, price, "what if I forget the master password"): {friction}
- My most important accounts (bank, email, work, social): {important_accounts}

YOUR TASK — answer in this exact order:
1. THE CORE IDEA: why unique passwords + one strong master password beats memorization — in 3 lines a skeptic accepts.
2. PICK A MANAGER: 2–3 reputable options compared honestly (free vs paid, my {devices} coverage), and the one to start with today.
3. THE MIGRATION ORDER: my {important_accounts} ranked — which 3 accounts to fix TODAY (hint: email first — it resets everything else), and the weekly habit for the rest.
4. THE MASTER PASSWORD: how to create one strong and memorable (passphrase method with a worked example — never ask for my actual one).
5. EMERGENCY PLAN: what happens if I lose the master password — the recovery options to set up NOW, and the realistic worst case if I don't.

RULES
If critical facts are missing (which accounts, which devices, current reuse level), ask up to 3 clarifying questions; never request real passwords or recovery codes.
- Never request, generate-for-me, or store my real passwords — this prompt designs the system only.
- No fear-mongering; each recommendation comes with the practical "why".
- Free options are acceptable and named as such — security isn't a subscription.
Note: Never ask for or accept real passwords, recovery codes, card numbers, or OTP codes — if I paste one, tell me to rotate it immediately and continue using placeholders.

OUTPUT FORMAT
- Five numbered sections: core idea (3 lines), 2-3 manager options compared + today's pick, migration order (email first), passphrase method with a fictional worked example, recovery plan. Lead with THE CORE IDEA.
